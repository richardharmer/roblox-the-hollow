# Design record

Task order: identify event/date → find a game/task/reward → track progress → inspect source.

Tokens: background #101014; surface #19191F; elevated #23232B; brand #E54149; darker CTA #BE2937; orange #F59E52; foreground #F5F2F0; secondary #AAA5B1; border #34313B. Body Arial/Helvetica system sans avoids a render-blocking font request. Editorial hero Georgia is intentionally distinct from database labels.

Original identity: a pointed doorway with a lightning-shaped opening. Standalone SVG, 16px/32px favicons, 180px touch icon and social card are configured. Forest doorway illustration is decorative and identified as original art, not event gameplay. No unauthorized competitor screenshots or Roblox marks.

UI uses compact grids for task destinations, separate evidence/watch status, static SVG hero, visible focus, 44px primary controls, native details FAQ, mobile menu and reduced-motion support. No fake rewards or inflated totals. Mobile card body text was increased to 14px; prose/forms remain 15–16px. No signup or password flow.

Skill search: first generic gaming design-system result recommended purple/3D showcase, which conflicts with brief and performance goals. A targeted style search returned dark-mode, data-dense dashboard and editorial-grid guidance. Only relevant principles were applied; generic marketing/social-proof sections were not adopted.
