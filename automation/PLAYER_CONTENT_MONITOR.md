# 玩家内容自动维护

用户已授权：核实后直接修改、提交 main、部署并验证正式站，无需再次申请发布许可。

## 每轮优先级

1. The Hollow 2026 兑换码：原始代码、奖励、兑换位置、限制、截止时间、可用性；排除同名 Bleach 游戏 HOLLOW。
2. 免费奖励：任务要求、Tickets 成本、会员/付费条件、领取位置和成功确认。
3. 每日/每夜新任务：迷宫流程、参与游戏任务、前置条件、路线、奖励和常见失败原因。
4. Tickets：获取方式、每项数量、是否可重复、回 Hub Confirm、Avatar Items 兑换。
5. 复核现有内容：到期、失效、价格变化、领取问题。

官方消息与链接仅作辅助证据。不得用只更新消息或入口代替上述内容。

## 证据标准

从现有 research 记录和 sources 开始，主动查找当日及近期变化。核对官方/开发者原文、游戏与徽章 API；查阅 SharkBlox、WaffleTrades、KAM Gats 等原始实录及新发现的可靠来源。视频须实际读取字幕/完整相关片段并查看关键画面，记录时间戳。标题、搜索摘要、互相转载及单条评论只能作线索。

字幕导出失败不等于视频不可核验：立即尝试原视频播放、页面自带转写文稿和完整相关片段画面，跳过可跳过广告，记录实际看到的步骤与结果。不得连续多轮仅重试同一字幕接口后宣告无变化。已有新夜攻略线索却未能读到视频时，必须记录具体障碍并尝试其他原始完整实录；持续执行失败应通知，不得伪装为无新增。

官方明确支持的事实可标 CONFIRMED。完整实录支持、活动身份交叉核实的攻略可标 REPORTED/视频核验，不得声称亲自账号实测。可用码需原始发布与当前适用证据或可复核的成功兑换记录；无有效码时如实写暂无核实。不得把普通 catalog 价格当 Tickets，不得把 Plus 物品列入免费，不得将徽章存在或启用当作成功领取证明。

到期/失效必须有明确截止时间或直接证据。403、限流、源站不可读、缺少搜索结果只能表示本轮无法复核，不能自动判失效或伪造核验日期。截止时间仅适用其明确限定的项目。确认失效后保留历史详情，显著标注并移出当前可领推荐。

## 实际交付

同步维护首页、/rewards/、/quests/、相关详情和来源记录：写清完整步骤、成本、限制、奖励、领取确认和排错，使用户留在本站即可读懂。新码出现时实现/更新站内复制代码与可用、过期、待核实分组；不发布空壳代码页。每日新任务保留日期/夜次区别。更新首页摘要，避免固定的 Night 1、数量和日期长期失真。

先检查工作区与远端，保留其他人的改动并去重。运行 npm run check；交互变更验证移动端、领取入口、筛选或复制。中文提交，合并远端后推送 main；验证 Cloudflare 成功、正式域名 /version.json 与完整 commit SHA 一致，并读取变更页面及站内链接。仅推送不能报告已上线。失败应修复并如实说明。

## 执行分工

GitHub Actions 保持每 30 分钟的活动期基础 API/公告扫描、发布门禁和生产验证。Codex 本对话的每小时定时任务负责上述完整研究、内容编辑及自动上线；它是本地执行任务，不等同于 GitHub 云端脚本。既有 ChatGPT 云端报告任务不在此仓库管理。

无实质变化时保持安静；仅就有价值的上线、重要失效/更正、执行失败或确需用户操作通知，给出站内链接及证据限制。

## 游戏详情页的玩家价值检查

每轮检查已有任务和奖励是否同步到对应 /games/{slug}/，不能在独立攻略已发布后仍显示“暂无已核实任务”。游戏页优先展示具体目标、任务所在位置（原游戏或 Hub）、完整步骤、领取确认、成本限制和排错；背景介绍置于次要位置。没有完整证据的游戏显示具体待核实项目，不以通用玩法介绍冒充活动攻略。新增录像须直接核对完整相关片段及关键画面，不能因搜索引擎未收录或字幕导出失败停止研究。
